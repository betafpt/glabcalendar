# Screen Specifications

## Today Dashboard
Reference language: approved calendar/project images + secondary Today mockups.

Structure:
1. small date/meta row
2. huge `TODAY*` heading
3. horizontal 7-day selector
4. vertical chronological event list
5. pastel event cards with time, type, location, avatars, thumbnail, chevron
6. sticky bottom nav
7. top-right quick add

Interactions:
- horizontal day swipe
- tap event → shoot/event detail
- long press / action menu
- add button → quick create sheet

## Calendar — Month
- huge CALENDAR or MONTH heading
- segmented control: Week / Month / Timeline
- full month grid
- compact pastel event markers/cards inside dates
- selected date strongly highlighted in black
- tapping date updates "upcoming/selected day" section
- plus/search/filter affordances

## Calendar — Week
- seven-day strip
- hour timeline
- colored event blocks aligned to time
- conflict overlaps visually obvious
- drag event vertically to change time
- drag horizontally to change day

## Projects List
- huge PROJECTS* heading
- status filter chips
- vertical cards with project photo, name, location, crew/shoot/deliverable metrics, status and progress
- strong pastel block per card

## Project Detail
- hero image
- giant project title
- date badge
- overview metrics
- crew avatar row
- gear chips/thumbnails
- notes
- sticky CTA such as "Ready for Call Time"

## Shoot Detail
Tabs:
- Overview
- Crew
- Gear
- Checklist
- Notes

Content includes:
- project visual + shoot title
- date/time/location/status
- visual references
- deliverables / progress
- completion CTA

## New Shoot
Prefer a step-based flow rather than a huge form.
Steps:
1. Basics
2. Location
3. Crew
4. Gear
5. Review

Fields:
- title
- date/time/call time
- location
- project/client
- shoot type
- crew
- gear
- notes

Use cards, chips, avatar selectors, and thumbnails — not a plain settings form.

## Checklist / Readiness
- shoot summary card
- huge readiness percentage
- animated progress bar
- checklist rows with icon + title + subtitle + optional thumbnail
- completion states
- sticky "Ready for Call Time" CTA

## Crew List
- huge CREW* heading
- filters: All / Available / On Set / Busy
- cards with portrait, role, availability dot, current/next assignment, thumbnail

## Crew Detail
- giant person name
- role
- portrait
- contact rows
- weekly availability strip
- schedule conflict banner if needed
- today's timeline
- assigned projects
- notes/skills

## Gear Library
- huge GEAR* heading
- category filters
- category sections using pastel horizontal groups
- equipment thumbnails and status chips

## Gear Detail
- giant equipment name
- status chips
- hero product image
- model/serial/weight/kit metadata
- booking timeline
- clear booking conflict banner
- upcoming bookings
- related accessories

## Clients
- huge CLIENTS* heading
- search
- filter/status chips
- client cards: identity/logo, active project count, last activity, avatar stack

## Client Detail
- hero/brand mark or client cover
- overview, projects, contacts, notes tabs
- company/contact information
- related projects

## Login / Onboarding
- preserve the editorial G.LAB visual style
- hero imagery
- bold brand headline
- Google sign-in / Apple sign-in / email
- minimal fields
- visually stronger than generic auth UI

## Google Calendar Sync
- settings/integration page
- Google account state
- connected/disconnected status
- one/two-way sync controls
- calendars included
- last sync / error state
- explicit conflict behavior

## AI Assistant
- chat-like assistant but styled as the same editorial app
- quick actions: create shoot, create call sheet, check crew availability, find free gear, summarize schedule
- structured response cards should be actionable
- preview proposed changes before committing scheduling changes
